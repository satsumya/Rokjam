# ROKJ-15: Member profile

Applies [Standards](../Standards.md) unless noted below.

- [x] Optional: Add a user name
- [x] Required: Add a gym or climbing location/address name (could be an indoor gym or an outdoor spot)
- [x] First location added defaults to home/base location
- [x] Optional: add more locations (not strongly prompted)
- [x] Optional: location nickname
- [x] Add difficulty levels for each location
- [x] One difficultly level added by default
- [x] Optional: for user to add more difficulty levels (strongly encouraged)
- [x] When adding levels, each level added has a default name and colour assigned
- [x] Default levels from easy to hard: Yellow > Blue > Purple > Green > Orange > Red > Black > White > Pink > [blank: user has to choose a colour and name]
- [x] A user can update the colour or name before confirming adding the level
- [x] Can edit levels after they’ve been added
- [x] Can reorder the added levels
- [x] Option to add strengths
- [x] Option to add areas to improve
- [x] Profile pic
- [x] After completing user goes to the dashboard
- [x] Happy path
- [x] Alternate paths
- [x] Error paths

**Review updates**
- [x] Need to be able to exit member profile — Some fields are required for users to use other features but users can still exit the member profile set up if they want to
- [ ] Location added - encourage user to add levels — When a location is added it needs to feel more seamless to move users onto adding difficulty levels
- [x] Location edit — After a location is added a user needs to be able to edit the location easily if they made a mistake or need to update the location
- [x] Difficulty levels sort — Make it clear they are adding level from easy to hard and allow users to swap the sorting from hard to easy
- [ ] Remove level numbers — e.g. Level 1 name should just be “Level label”
- [x] Changing level colours — Allow users to click on the colour to open a menu or dropdown of the default colour types or click a plus button to choose from a colour wheel with hex code available
- [x] Difficulty levels - removing — If a user adds too many difficulty levels they need to be able to remove a level if they want. But a user should not be able to delete the level if there’s no other levels added to the location
- [ ] Be concise when displaying levels — Try showing levels as a row so it’s less overwhelming and easier for users to see more levels
- [x] Difficulty level rearranging — Users should also be able to drag the levels to a different position as well as moving with arrows
- [x] Locations added — Only show one location with levels at a time. e.g. an accordion for each location, only allow one location accordion open at any time
- [x] Change home location — Users need to be able to change which location is considered the ‘home’
