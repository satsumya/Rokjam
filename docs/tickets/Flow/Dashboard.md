# Dashboard

Applies [Standards](../Standards.md) unless noted below.

- [x] Blank profile dashboard — Incomplete / skipped profile shows **Add username** (inline edit with availability checks), no strength/improve tags, and prompts to complete profile
- [x] user can change the time frame
- [x] Session duration trend — contribution heatmap by day, total climbing time, hours and minutes
- [x] Timeframe subtitle shows the date or month range (not a generic “month view” label)
- [x] Trends / many-sessions demos use dense varied history (2–3×/week, mixed durations, mostly home + occasional other gym)
- [x] Difficulty trend
- [x] Difficulty trend is a pie chart coloured by difficulty level
- [x] Difficulty insights are scoped per location (tabs when few locations, dropdown when many)
- [x] Defaults to home gym when it has session data; otherwise first other location with data
- [x] Celebrate standout climbs
- [x] Warm up climb count trend
- [x] Auto pull any other stand out trends
- [x] e.g. first dyno sent, first Orange difficulty climb sent
- [x] Most attempted climb (your latest project)
- [x] Most difficult flashed climb
